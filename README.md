--------------------------------- backup_file.sh --------------------------------------------
backup_file.sh
	Создает копию указанного файла с расширение .bak, прибавляя к наименованию файла дату и время создания 
	Формат запуска : backup_file.sh /path_to_file/file.name
	Результат: file.name_YYYYMMDD_hhmmss

------------------------------- max_work.sh ------------------------------------------------
max_work.sh
	MAX запускается из контейнера
	-	проверяется наличие необходимых компонентов 
	-	в случае "сна" docker на машине - запускает его
	-	подключает контейнер и запускает MAX из контейнера (основа образа UBUNTU 24.02)
	-	по окончании работы с мессенджером задает вопрос о необходимости работы docker и если таковая необходимость отсутсвует выгружает его из системы (останавливает работу docker)
